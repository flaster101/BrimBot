# BrimBot 0.1.0-preview

**Observation preview only. This APK does not play Blades of Brim.** The requested
autonomous player remains unfinished; gameplay gestures are disabled.

## Included

- Native Kotlin / Material 3 interface, onboarding, permission guidance and Stop.
- Local screen analysis with an embedded 38,980-byte trained surface candidate.
- Android MediaProjection capture and notification Stop; no internet permission,
  recording, game-memory access, modified game files or downloaded runtime models.
- Source, research, dataset provenance, training histories and explicit limitations.

## Validation actually performed

- 45 Python tests, 12 Kotlin/JVM tests, four Android 15 emulator tests passed.
- Actual capture consent, frame receipt, rotation and notification Stop exercised.
- Every model output compared against Python golden values within 0.0001.
- Signed release installed and cold-launched successfully on the emulator.
- Two surface models trained; selected CNN pseudo-label IoU 93.93% on 19 validation
  frames. This is teacher agreement, **not safe-path accuracy**.
- Separate-source replay: 21,096 decoded frames, 7,032 analyzed at 9.99 Hz over
  approximately 704 seconds. All decisions abstained. No autonomous survival result.

## Installation

Download `BrimBot.apk` and install on Android 8.0 or later. Complete onboarding,
install/open Blades of Brim separately, and use **START PREVIEW** to follow the
Android permission flow. You remain responsible for playing. Stop through the
app or its notification. No scripts, model choices or coordinate setup are needed.

## Remaining limitations

No reliable enemy, lethal-hazard, player-state, mission-OCR or safe-path estimator;
no closed-loop gameplay, physical-phone performance or thermal evaluation. Six
screen geometries have numerical mapping tests; actual app testing used one
Android 15 emulator. This prerelease is not a finished autonomous bot.
